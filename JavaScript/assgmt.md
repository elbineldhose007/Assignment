## 18. What is a database? Why is it used?

## 19. What is the difference between a server and a database?

__*Server*:__ A computer or software that _provides services_ by processing requests from clients.  
Ex: Web server sends you websites when you open a browser.

__*Database*:__ An organized collection of data stored for _easy access, update, and management_.  
Ex: Stores all your bank account details, Instagram posts, etc.

__*Main difference*:__
A _server does the work_ and responds to requests. A _database stores the data_ that the server often needs to do that work.

__*Analogy*:__ Server = waiter who serves food. Database = kitchen pantry where ingredients are kept.

## 20. Explain the client-server architecture.
*Definition*: A network model where _clients_ request services/data and _servers_ provide them.

__*How it works:*__
1. *Client*: The device/app that _asks_ for something. Ex: Your phone, browser, WhatsApp app.
2. *Server*: The system that _processes the request_ and _sends back_ the result. Ex: WhatsApp server, web server.
3. *Network*: Connects client and server. Ex: Internet, Wi-Fi.

__*Key points:*__
1. *Centralized*: Server holds resources; clients don’t store everything.
2. *Many-to-one*: One server can handle many clients at once.
3. *Examples*: Browsing Google, online banking, multiplayer games, email.

*Flow*: Client sends request → Server processes → Server sends response → Client displays it.
## 21. What happens when you type a URL in a browser?

1. __*You press Enter*:__ Browser checks if you typed a search or a full URL like `https://www.google.com`.

2. __*DNS Lookup*:__ Browser asks a DNS server to convert the domain name `www.google.com` into an IP address like `142.250.183.68`.

3. __*Connect to Server*:__ Browser opens a TCP connection to that IP address using port 443 for HTTPS or 80 for HTTP.

4. __*Send HTTP Request*:__ Browser sends a request saying "GET /" to the web server.

5. __*Server Responds*:__ The server processes the request, often fetching data from a database, and sends back HTML, CSS, JS files.

6. __*Browser Renders*:__ Browser reads the HTML/CSS/JS and displays the webpage on your screen.

7. __*More Requests*:__ Browser then requests extra files like images, fonts, videos to fully load the page.
## 22. What is a client in a client-server model?

A __"client"__ is the device or software that _requests services or data_ from a server.

__key points:__
1. __*Role*:__ Initiates communication by sending requests. It doesn’t serve others.
2. __*Examples*:__ Your web browser, mobile apps like WhatsApp, email apps, games on your phone.
3. __*Function*:__ Displays data, takes user input, and relies on the server for processing/storage.
4. __*Dependency*:__ Cannot work fully without a server if the data/service is on the server.

*In short*: _Client asks, server answers._ Your phone running Instagram is the client; Instagram’s servers are the server.
## 23. What is the role of a browser in accessing the web?
A *browser* is the client software you use to access and view websites on the internet.

__*Main roles:*__
1. __*Request pages*:__ Takes the URL you type and sends a request to the web server.
2. __*Interpret code*:__ Reads HTML, CSS, and JavaScript sent by the server.
3. __*Render content*:__ Converts that code into the visual webpage you see and interact with.
4. __*Handle protocols*:__ Uses HTTP/HTTPS to communicate securely with servers.
5. __*Manage features*:__ Stores cookies, runs scripts, plays videos, handles tabs, bookmarks, and security warnings.

Examples: Chrome, Firefox, Safari, Edge.

__In short:__ _Browser = your window to the web._ It asks servers for webpages and turns code into the sites you use.
